1. Overview

Athanni Softech's Voice Calling Agent is an enterprise voice AI solution delivering human-grade telephone and web conversations with ultra-low latency (<700ms). Powered by WebRTC audio streaming, continuous speech recognition (Deepgram Nova-2), and neural voice synthesis (ElevenLabs), this agent automates customer qualification, booking, and 24/7 support without human intervention.

2. Complete Feature Matrix

• Sub-700ms Streaming Latency

Zero awkward delay via peer-to-peer WebRTC voice piping.

• Neural Voice Synthesis (ElevenLabs)

Natural human intonation, emotional inflection, and dynamic pacing.

• Real-Time ASR (Deepgram Nova-2)

Multi-accent transcription handling fast speech and noisy backgrounds.

• Natural Barge-In & Interruption

Callers can speak over the AI mid-sentence; agent halts and listens instantly.

• 3D Audio-Reactive Voice Orb

Animated visualizer across Idle, Connecting, Listening, Thinking, and Speaking.

• Live Dual-Channel Transcript

Real-time chat transcript with role avatars, timestamps, and 1-click clipboard copy.

• In-Call Audio Controls

Live call timer, instant mic mute/unmute, and clean WebRTC teardown.

• Automated CRM Webhooks

Pushes call summaries, audio recordings, and extracted leads to HubSpot/Make.

Snippet 2: React / Next.js Component (Real Code from src/App.jsx)

Uses @vapi-ai/web for custom WebRTC call state and live streaming transcripts:

import { useEffect, useState, useRef } from 'react';
import Vapi from '@vapi-ai/web';

const vapi = new Vapi('90fb2000-8816-4057-9c1a-2c94bd7dfa67');
const ASSISTANT_ID = '4979a054-806c-45d1-bf84-e83f8a58d61e';

export default function VoiceAgentButton() {
  const [status, setStatus] = useState('idle'); // idle | listening | speaking | thinking
  const [messages, setMessages] = useState([]);

  useEffect(() => {
    vapi.on('call-start', () => setStatus('listening'));
    vapi.on('call-end', () => setStatus('idle'));
    vapi.on('speech-start', () => setStatus('speaking'));
    vapi.on('speech-end', () => setStatus('listening'));
    vapi.on('message', (msg) => {
      if (msg.type === 'transcript') {
        setMessages((prev) => [...prev, { role: msg.role, text: msg.transcript }]);
      }
    });
    return () => vapi.stop();
  }, []);

  const handleToggleCall = () => {
    if (status === 'idle') {
      vapi.start(ASSISTANT_ID);
    } else {
      vapi.stop();
    }
  };

  return (
    <button onClick={handleToggleCall} className="btn-voice">
      {status === 'idle' ? 'Start Voice Call' : 'End Call (' + status + ')'}
    </button>
  );
}
